# TypeScript — not yet ported

The TypeScript implementation of this recipe does not exist yet. Python is the reference
implementation; ports land beside it.

When it does, it will live here as `reasoningAcrossTurns.ts` with its own `package.json` and
`tsconfig.json`. `reasoning: { effort, context }` is a plain request field in the Node SDK,
and carrying `response.output` forward unmodified works the same way.

The recipe's narrative lives once in [`cookbooks/02-reasoning-and-output/04-reasoning-across-turns/README.md`](../README.md) and applies to both
languages.
