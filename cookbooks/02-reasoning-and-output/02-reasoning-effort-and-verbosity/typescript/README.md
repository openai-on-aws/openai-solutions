# TypeScript — not yet ported

The TypeScript implementation of this recipe does not exist yet. Python is the reference
implementation; ports land beside it.

When it does, it will live here as `effortAndVerbosity.ts` with its own `package.json` and
`tsconfig.json` — which is why each language gets a directory rather than sitting beside
the README. Both parameters are plain request fields in the Node SDK: `reasoning: { effort }`
and `text: { verbosity }`.

The recipe's narrative — the task, the measured sweep, the production notes — lives once in
[`cookbooks/02-reasoning-and-output/02-reasoning-effort-and-verbosity/README.md`](../README.md) and applies to both languages.
