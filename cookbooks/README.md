# Cookbooks

Runnable, task-focused examples for building OpenAI-powered applications on AWS.

Each cookbook should:

- solve one clearly defined problem;
- include prerequisites, setup, and cleanup instructions;
- keep deployable code beside the guide;
- call out AWS services, OpenAI APIs, costs, and security considerations; and
- be independently testable.

Demos belong here when they teach a reproducible workflow rather than only showcasing a
finished experience.
