title: Open The Starter Workspace
summary: Download the participant starter and open it as the Codex Desktop working directory.
phase: Workspace Setup
---

Begin by opening the participant starter as the working directory for the workshop. All later Codex actions run from this folder.

- Download [azure-bedrock-workshop-main.zip](/downloads/azure-bedrock-workshop-main.zip).
- Extract the ZIP to a local working folder.
- Open the extracted folder as a project in Codex Desktop.

Continue when Codex Desktop shows the extracted starter folder as the active working directory.
