# Contributing

This repository hosts the public task-card hub for a Codex Desktop migration workshop.

Before opening a change:

- Keep the hub and participant starter separate.
- Do not add credentials, customer data, local paths, or generated workshop artifacts.
- Keep task cards clear, copyable, and grounded in documented Bedrock Mantle behavior.
- Rebuild the starter ZIP only from the clean participant starter workspace.
- Run `npm run lint` and `npm run build`.

Security-sensitive reports should not be opened as public issues.
