# Migration Blueprint

The main session creates a migration context, then delegates one evidence-producing step at a time. Discovery identifies source behavior and Azure dependencies. Architecture ranks AWS workload archetypes and maps Chat Completions to Responses. Validation challenges every claim. Deployment engineering packages only the approved decision.

The migration contract covers roles, message construction, tools, structured output, streaming, modalities, state, parameters, errors, retries, output parsing, usage, identity, data, and public interfaces. Unsupported behavior produces either a narrowly scoped remediation proposal or a factual blocker.

`APPROVE MIGRATION` authorizes behavior-preserving code and architecture changes. `DEPLOY` authorizes resource creation after preflight. `DESTROY` authorizes teardown. Production data movement is not part of the workshop.
