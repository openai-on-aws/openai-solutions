# Code Of Conduct

This workshop should be a practical, respectful place for builders to learn and improve Codex-on-Bedrock workflows.

Expected behavior:

- Be constructive and specific in feedback.
- Assume good intent, especially when someone is learning a new provider or toolchain.
- Keep examples safe: no real credentials, customer data, or private account details.
- Respect maintainers' decisions about scope, safety defaults, and public-facing clarity.

Unacceptable behavior includes harassment, personal attacks, sharing sensitive data, or pressuring others to bypass security review.

If there is a conduct concern, contact the maintainers through the private channel used by the hosting organization.
